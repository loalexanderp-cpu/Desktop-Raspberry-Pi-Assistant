# Desktop-Raspberry-Pi-Assistant
Desktop assistant using a Raspberry Pi. Touchscreen desktop assistant featuring Spotify lyrics, alarms, weather, environmental monitoring, and a custom PCB HAT. Built with Python and Qt. Built for Fabricate by Hack Club.
